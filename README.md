DFE is a Windows desktop app for investing in the US stock market and planning your own money. What it does, with
pictures, is on the [core page](https://github.com/hdent1232/daily-finance-engine).

## Getting nightly builds

In the app, open **Settings → Updates → Channel** and choose **Nightly**. The app then offers each build here as soon as
it is published, and offers the last good build if the one you are running is found faulty.

Copies of the app from before this page existed (2.9.76 and earlier) read only the core page. They see builds here once
they have updated to the next core build.

To download a build by hand, open **[Releases](https://github.com/hdent1232/daily-finance-engine-nightly/releases)** and
take **`DailyFinanceEngine.exe`** from the newest build not marked faulty.

## Privacy

This repository holds only the compiled app and this page. Your data, settings, broker logins and keys live only on
your own PC, in the app's data folder, and are never uploaded. Every build is scanned for personal data before it is
published.
